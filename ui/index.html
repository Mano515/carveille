Comment voulez-vous etre alerte ?
Comment configurer Telegram : 1. Ouvrez Telegram et cherchez @BotFather
2. Envoyez /newbot et suivez les instructions — notez le Token
3. Envoyez un message a votre nouveau bot, puis allez sur :
   https://api.telegram.org/botVOTRE_TOKEN/getUpdates
4. Notez le Chat ID (nombre dans "id")
Pour Gmail : Activez la validation en deux etapes, puis creez un mot de passe d'application dans les parametres de securite de votre compte Google. Utilisez ce mot de passe (pas votre mot de passe habituel) dans le champ ci-dessous.
